## 📱 Usage Example (JavaScript)

```javascript
// Register
const register = await fetch('/e_rentalHub/api/register.php', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    username: 'John Doe',
    email: 'john@example.com',
    password: 'password123',
    role: 'student'
  })
});

// Login
const login = await fetch('/e_rentalHub/api/login.php', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'john@example.com',
    password: 'password123'
  })
});

// Get Properties
const properties = await fetch('/e_rentalHub/api/get_properties.php?city=Nairobi&limit=10');

// Search
const search = await fetch('/e_rentalHub/api/search_properties.php?q=apartment');

// Save Property
const save = await fetch('/e_rentalHub/api/save_property.php', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ property_id: 1 })
});

// Create Booking
const booking = await fetch('/e_rentalHub/api/create_booking.php', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    property_id: 1,
    check_in_date: '2024-06-01',
    check_out_date: '2024-12-31'
  })
});

// Get My Bookings
const myBookings = await fetch('/e_rentalHub/api/get_my_bookings.php', {
  credentials: 'include'
});
```

## 🚀 Quick Start

### 1. Access API Documentation
Visit: `http://localhost/e_rentalHub/api/`

### 2. Register User
```bash
curl -X POST http://localhost/e_rentalHub/api/register.php \
  -H "Content-Type: application/json" \
  -d '{
    "username": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "role": "student"
  }'
```

### 3. Get Properties
```bash
curl "http://localhost/e_rentalHub/api/get_properties.php?limit=10"
```

### 4. Search Properties
```bash
curl "http://localhost/e_rentalHub/api/search_properties.php?q=apartment"
```
